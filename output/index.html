Method

Each coal source's landed cost is modelled as Landed = Rate + Freight (Rs/MT), consistent with the source workbook (the quoted Premium% is contractual context on bridge-linkage rates and isn't separately added). Variable charge is VC = Landed × SCC ÷ (1 − APC%) ÷ 1000 for the Formula VC reference column only — the actual optimizer input is the editable Current VC. There are two distinct optimizers here: the Preview buttons run a bounded fractional (water-filling) allocation entirely in your browser, one plant at a time, with no cross-plant company conservation — useful for a fast what-if, not authoritative. The “Optimize Allocation (OR-Tools)” button is the only official result: it sends the whole portfolio to a Google OR-Tools solver on the backend, which enforces exact company-wide conservation, plant-total bounds, and integer rakes across all plants at once. This is a planning aid built from the uploaded worksheet; it does not reflect real-time rake booking, FSA trigger-level obligations, or CIL allocation decisions, and every input cell remains editable.

Reading the panel

Current Rakes default to each plant's July-2026 rake receipts (falling back to the MSQ rake share where receipts aren't recorded) and are fully editable. Min/Max % default to the current split ± the flex band below the source table — widen a source's Max to let the Preview optimizer lean on it harder, or raise its Min to protect a contractual floor. A plant with no feasible Preview mix under its current caps shows the shortfall and the cheapest source to unlock.
